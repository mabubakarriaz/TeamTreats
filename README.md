# Team Treats 🎉

Teamtreats is a web application designed to streamline the management of team recreational funds, making it easier for teams to allocate, track, and use resources for celebrations, outings, and other fun activities.

## Architecture & Methodology
- **The Twelve-Factor App Methodology**
  - Following best practices for building modern, scalable, and maintainable web applications.
- **Azure Well-Architected Framework**
  - Ensuring the application is secure, performant, resilient, and cost-optimized on Azure.
